METHOD
------
satisfiedEventsTypes is WhoScored's list of statistics an event counts towards.
Each id is one counter in their stats engine. The CSV only gives numbers, so each id
was decoded from the data itself:
  1. Parse every event row of France_vs_England.csv.
  2. For each id, list every row carrying it: type, outcomeType, x/y, endX/endY
     (metres, attacking towards x = 105), qualifiers, and the ids always present with it.
  3. Name the id from what is unique to its rows.
  4. Cross-check against WhoScored's stat-name order (matchCentreEventTypeJson).
Confidence: High = data pins the id alone; Medium = data fits but other readings remain;
Low = too few rows to separate it from its neighbours.
